# FreelanceHub Usage Guide

## Getting Started

### 1. Access the Platform
Navigate to the app home page. You'll see the landing page with an overview of FreelanceHub.

### 2. Create an Account
- Click "Register" in the navbar
- Choose role: Client or Freelancer
- Enter email and password
- Click "Register"

**Or use demo credentials:**
- Client: `client@demo.com` / `demo123`
- Freelancer: `freelancer@demo.com` / `demo123`

### 3. Browse Services (Client)
- Click "Browse Marketplace" from navbar
- Explore services by category
- Use filters to narrow results
- Click on a service to see details

### 4. Hire a Freelancer (Client)
- Click "Hire Now" on any service
- Complete the checkout form:
  1. Review order details
  2. Enter payment info (demo)
  3. Confirm order
- Order appears in your Client Dashboard

### 5. Communicate (Both)
- Access Messages from navbar or dashboard
- Click conversation to open chat
- Type message and press Enter
- See message history in real-time

### 6. Manage Work (Freelancer)
- View available jobs in Jobs tab
- Accept job to start work
- Communicate with client
- Mark job as completed

### 7. View Dashboard (Both)
**Client Dashboard**: `/client-dashboard`
- Overview of your spending and activity
- Manage active and completed orders
- Track messages and communications
- Update profile

**Freelancer Dashboard**: `/freelancer-dashboard`
- Overview of earnings and activity
- View and manage available jobs
- Communicate with clients
- Manage your professional profile

## Common Tasks

### As a Client

#### Find a Service
1. Go to Marketplace
2. Browse categories or search
3. Filter by price or rating
4. Click service to see details
5. Read description and reviews

#### Hire a Freelancer
1. Find and open service
2. Click "Hire Now"
3. Complete checkout form
4. Confirm order
5. Check Client Dashboard for order status

#### Message a Freelancer
**Option 1**: From service page
- Click "Contact Seller"
- Opens direct chat with freelancer

**Option 2**: From orders
- Go to Client Dashboard → Orders
- Find order
- Click "Message Seller"

**Option 3**: From messages
- Go to Messages
- Click existing conversation
- Or start new conversation

#### Track Order Progress
1. Go to Client Dashboard
2. Click Orders tab
3. Find your order
4. Check status (Pending, Active, Completed)
5. Message freelancer for updates

#### Review Work
1. Order shows "Awaiting Approval"
2. Review delivered work
3. Click "Approve" or "Request Revision"
4. After approval, option to review freelancer

### As a Freelancer

#### View Available Work
1. Go to Freelancer Dashboard
2. Click Jobs tab
3. Browse available projects
4. Review requirements and pay
5. Click "Accept Job" to start

#### Manage Jobs
1. Freelancer Dashboard → Jobs
2. See all active jobs
3. Update job status as you progress
4. Message client with updates
5. Mark as complete when done

#### Update Your Profile
1. Go to Freelancer Dashboard
2. Click Profile tab
3. Edit information:
   - Bio/title
   - Skills
   - Hourly rate
   - Portfolio
4. Click Save

#### Communicate with Clients
1. Go to Messages (navbar or dashboard)
2. Click conversation
3. Type messages in chat
4. Share project details and timelines
5. Send files/links in messages

#### Track Earnings
1. Freelancer Dashboard → Overview
2. See total earnings
3. View completed jobs
4. Access invoices/receipts

## Tips & Best Practices

### For Clients

1. **Be Specific**: Provide clear requirements in messages
2. **Communicate Early**: Discuss timeline and expectations upfront
3. **Review Regularly**: Check order progress frequently
4. **Give Feedback**: Detailed feedback helps freelancers improve
5. **Rate Honestly**: Leave honest reviews to help the community

### For Freelancers

1. **Professional Profile**: Complete your profile with real information
2. **Clear Pricing**: Be transparent about what's included in service
3. **Responsive Communication**: Reply to messages quickly
4. **Quality Work**: Deliver high-quality work consistently
5. **Documentation**: Keep work organized and well-documented

## Troubleshooting

### I Can't Log In
- Check email and password spelling
- Try demo credentials first
- Clear browser cache
- Try different browser

### My Data Disappeared
- Check if you cleared browser cache/localStorage
- Private/Incognito mode doesn't save data
- Try logging in again
- Check different browser

### Messages Not Showing
- Refresh the page
- Check you're on the correct chat
- Verify message was sent
- Check browser console for errors

### Order Didn't Save
- Complete checkout fully (all steps)
- Check Client Dashboard after
- Try order again if failed
- Contact support if persistent

## Account Management

### Change Profile Information
1. Go to respective Dashboard (Client/Freelancer)
2. Click Profile tab
3. Edit fields
4. Click Save

### Change Password
- Currently not supported in demo
- Feature planned for future

### Delete Account
- Currently not supported in demo
- Data persists in localStorage
- Clear manually via browser tools

### Logout
- Click Logout in navbar
- Confirms logout (optional)
- Clears all session data
- Redirects to home page
